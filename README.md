## Сценарии руководства

1. Создать заявку без вложений и открыть по номеру.
2. Приложить файлы и исправить отказ из-за четвёртого файла.
3. Сетевой тайм-аут: проверить, не сохранилась ли заявка, прежде чем отправлять снова.
4. Техник: найти назначенную заявку, перевести в работу и завершить с комментарием.
5. Отказ доступа: вернуться к разрешённому списку.

## Ограничения

- Испытание документа **аналитическое**: стенд не предоставлен, реальное поведение приложения не подтверждается.
- Названия кнопок и сообщений взяты дословно из `data/operator_observations.md`.
- Скриншоты не создавались: элементы интерфейса описаны по модели, а не получены из настоящего сервиса.
- Административные действия (назначение исполнителя, роли, миграции) в руководство не входят — обозначены как обращение в поддержку.
