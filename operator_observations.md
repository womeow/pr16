# Синтетические наблюдения интерфейса версии 1.5.0


Экран «Заявки»: список с полями номер, тема, статус; кнопка «Создать»; фильтры «Мои» и «Назначенные». Оператор видит только свои заявки; техник только назначенные. Менеджер видит все.


Экран «Новая заявка»: поля «Тема», «Описание», «Вложения»; кнопки «Отправить» и «Отмена». После сохранения показано «Заявка LAB-104 создана» со ссылкой «Открыть». При четвертом файле показано «Можно приложить не более 3 файлов»; текст остается в форме. При недоступной сети показано «Не удалось получить ответ. Проверьте список заявок перед повтором».


Карточка LAB-101: автор `operator_a`, тема «Проектор 204», статус open, исполнитель `technician_a`, вложение screen.png. `operator_b` карточку не видит. У `technician_a` есть кнопка «В работу», затем «Отметить выполненной» с обязательным комментарием; кнопки удаления нет.


Экран ошибки доступа показывает «Нет доступа к этой заявке» и ссылку «К списку». Не показывает имя автора, описание, вложения или другие закрытые сведения.


Сценарий O-01: `operator_a` создал LAB-104 и повторно открыл карточку. Сценарий O-02: `technician_a` перевел LAB-101 в `in_progress`, затем resolved с комментарием. Сценарий O-03: после тайм-аута `operator_a` нашел уже созданную LAB-105 в списке. Это готовые наблюдения учебного кейса, а не действия студента.
